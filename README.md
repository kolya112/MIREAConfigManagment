# C# UNIX-like Shell Emulator (REPL)

Кроссплатформенный эмулятор UNIX-like командной строки для ОС Windows / Linux / macOS, поддерживающий определенный перечень команд.

## Возможности

- Выполнение команд
- Работа с виртуальной файловой системой
- Разрешение переменных окружения

## Текущий список команд

| Команда | Описание | Пример |
| ------- | -------- | ------ |
| `cd`    | Смена рабочей директории | `cd /dev/null` |
| `ls`   | Вывод списка файлов текущей директории | `ls` |
| `du`   | Вывод размера файла или файлов в директории (рекурсивный обход) | `du` |
| `mv`   | Перемещение файла или директории по указанному пути | `mv /test1 /test2` |
| `history` | Вывод истории введенных команд | `history` |
| `exit` | Выход из программы | `exit` |
| `echo`  | Вывод строки в консоль | `echo $PATH` |
| `regvar` | Создание переменной окружения (для текущего процесса) | `regvar TEST_HOME /home/test` |

## Требования

Для запуска программы требуется установленная среда выполнения [.NET 10 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

Для сборки решения необходимы установленные инструменты разработчика [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

## Сборка решения

### Сборка CLI

Необходимо воспользоваться командой `dotnet build -c Release` из корня проекта терминала (`../src/MIREAConfigManagment`) для сборки проекта CLI.

### Выполнение тестов

Для выполнения тестов необходимо воспользоваться командой `dotnet test` из корня проекта тестирования (`../tests/REPLTests`).
